# СвойСтек — Telegram Bot + Mini App v0.2

Готовый MVP сервиса поиска проектов и людей по стеку.

## Что уже есть

- Telegram-бот `/start` и `/app`.
- Постоянная кнопка меню `СвойСтек`.
- Mini App с вкладками:
  - 🚀 Проекты
  - 👥 Люди
  - 📨 Отклики
  - 👤 Профиль
- Три формата:
  - 🟢 Бесплатно
  - 💼 Оплата
  - 💎 Доля / revenue share
- Поиск проектов и людей по стеку.
- Создание проекта.
- Профиль человека: роль, уровень, стек, занятость, описание.
- Отклик на проект через отдельное окно.
- Владелец проекта видит входящие отклики.
- Кнопки **Принять / Отказать**.
- После принятия соискатель видит Telegram автора проекта.
- Уведомления через бота о новом отклике и решении.
- Опциональная обязательная подписка на Telegram-канал.
- Проверка подписи `Telegram.WebApp.initData` на backend.
- SQLite для MVP.
- Готовый `render.yaml`.

## Локальный запуск на Windows

В папке проекта:

```powershell
py -m pip install -r requirements.txt
```

Создай `.env`:

```env
BOT_TOKEN=ТВОЙ_ТОКЕН
WEBAPP_URL=https://example.com
DEV_MODE=1
REQUIRED_CHANNEL=
```

Запуск:

```powershell
py -m uvicorn app:app --host 0.0.0.0 --port 8000
```

Открыть в браузере:

```text
http://127.0.0.1:8000
```

## Render

Проект уже содержит `render.yaml`.

1. Загрузи содержимое папки в GitHub.
2. Render → New → Blueprint.
3. Выбери репозиторий.
4. Введи `BOT_TOKEN`.
5. Deploy.

На Render URL берётся автоматически из `RENDER_EXTERNAL_URL`.
`WEBAPP_URL` вручную указывать не нужно.

## Обязательная подписка на канал

После деплоя в Render открой:

`Environment`

и добавь:

```env
REQUIRED_CHANNEL=@username_канала
```

Если переменная пустая — проверка подписки отключена.

Важно: бота нужно сделать администратором канала, чтобы он мог надёжно проверять подписку пользователей.

## Важно про базу

SQLite подходит для тестового MVP. На бесплатном Render локальные файлы нельзя считать постоянным production-хранилищем. Перед реальным запуском на аудиторию лучше перенести базу на PostgreSQL.
