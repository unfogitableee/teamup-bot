# Запуск «СвойСтек» на Render

Эта версия уже умеет автоматически брать свой публичный HTTPS URL из переменной
`RENDER_EXTERNAL_URL`, которую Render задаёт сам.

## Что получится

После деплоя будет адрес примерно:

`https://svoystek-bot.onrender.com`

И бот автоматически поставит этот адрес:
- в кнопку `/start`;
- в команду `/app`;
- в постоянную кнопку меню Telegram.

## Самый простой путь

1. Создай пустой репозиторий на GitHub, например `svoystek-bot`.
2. Загрузи в корень репозитория все файлы из этого архива.
3. Открой Render и создай **Blueprint** из этого GitHub-репозитория.
   Render увидит `render.yaml`.
4. Когда Render попросит значение `BOT_TOKEN`, вставь НОВЫЙ токен своего бота.
5. Создай сервис и дождись статуса **Live**.
6. Открой Telegram, отправь боту `/start`.
7. Нажми `🚀 Открыть Mini App`.

`WEBAPP_URL` вручную на Render задавать не требуется.

## Важно про бесплатный Render

На бесплатном тарифе Web Service засыпает после периода без входящих запросов.
Поэтому первый запуск после простоя может быть медленнее.

SQLite в бесплатном Web Service также не стоит считать постоянной production-базой:
при будущих деплоях/заменах инстанса данные могут потеряться. Для первых тестов это нормально.
Когда пойдут реальные пользователи, следующим шагом нужно перенести базу на PostgreSQL.

## Локальный запуск остаётся прежним

`.env`:

```env
BOT_TOKEN=...
WEBAPP_URL=https://example.com
DEV_MODE=1
```

Команда:

```powershell
py -m uvicorn app:app --host 0.0.0.0 --port 8000
```
